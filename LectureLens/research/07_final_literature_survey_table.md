## 2. Comprehensive Academic Synthesis

### 2.1 What Has Already Been Achieved?
Over the past decade, significant individual milestones have been established across specialized subfields:
1. **Multimodal Data Foundations:** The creation of datasets such as the **LPM Dataset (Lee et al., 2023)** and **MaViLS (Anderer et al., 2024)** proved that university lectures are fundamentally multimodal, requiring joint understanding of slides, video frames, and spoken language.
2. **Robust Speech Transduction:** **Whisper (Radford et al., 2023)** and **WhisperX (Bain et al., 2023)** made high-accuracy, multilingual speech transcription practical without custom acoustic models.
3. **Mathematical & Diagram OCR:** **Nougat (Blecher et al., 2024)** and **CoMER (Zhao & Gao, 2022)** demonstrated that Vision Transformers can parse complex LaTeX mathematical expressions from images.
4. **Retrieval-Augmented Generation:** **RAG (Lewis et al., 2020)** and **ALCE (Gao et al., 2023)** established frameworks for grounding LLM generation in external reference documents with citations.
5. **Real-Time WebRTC Media Routing:** **Jansen et al. (2018)** proved that Selective Forwarding Units (SFUs) provide the only scalable architecture for multi-party interactive video conferencing.

### 2.2 What Limitations Repeatedly Appear Across Prior Work?
Despite these achievements, a systematic review of the literature reveals five persistent, systemic limitations:
1. **Domain Invariance:** Existing multimodal alignment models apply uniform, static feature weights across all academic disciplines, ignoring the fact that mathematical formulas dominate STEM lectures while code identifiers dominate programming lectures.
2. **Monotonic Temporal Assumptions:** Alignment algorithms (DTW, CTW) assume that video lectures progress strictly forward in time, failing whenever an instructor revisits previous slides to answer questions.
3. **Single-Axis Hallucination Conflation:** Evaluators (FActScore, TRUE, SelfCheckGPT) collapse factual verification into a single scalar score, rendering them incapable of distinguishing between *faithful lecturer slips* (taught in class but factually wrong) and *out-of-scope truths* (scientifically true but absent from the lecture).
4. **Circular Prerequisite Traps:** Machine learning models for prerequisite extraction (LectureBank, VGAE) predict pairwise dependencies independently, inadvertently generating circular prerequisite cycles ($A \to B \to A$) that violate educational logic.
5. **Systemic Fragmentation:** The edtech ecosystem remains fractured into isolated tools (Zoom for video, Otter for transcripts, Mathpix for OCR, NotebookLM for notes), with zero unified synchronization between live video streams and generated study artifacts.

### 2.3 How LectureLens Addresses These Unresolved Gaps
LectureLens directly bridges these gaps through focused algorithmic innovations and end-to-end systems engineering:
1. **Subject-Adaptive Alignment (SALKG):** Formulates subject-conditioned feature weighting ($\mathbf{w}(\omega)$) boosting symbol overlap in Mathematics and code identifiers in CS, combined with non-monotonic dynamic programming sequence optimization with asymmetric lookback penalties ($\Phi_{base} + \lambda_{back} \Delta j$).
2. **Dual-Axis Verification (SALKG-Guard):** Establishes independent evaluations for **Lecture Faithfulness** ($\mathcal{F}$) and **Domain Correctness** ($\mathcal{D}$), catching lecturer slips and out-of-scope claims through deterministic subject validators and a bounded retry loop.
3. **Acyclic Pedagogical Knowledge Graphs:** Implements Kahn's topological sort algorithm to detect and break circular dependency cycles, guaranteeing cycle-free prerequisite DAGs with 100% provenance traceability.
4. **Integrated Enterprise Architecture:** Combines a low-latency WebRTC SFU gateway (Node.js/mediasoup) with an authoritative Spring Boot core (Java 21), a React 18 frontend, and an interactive **3D Educational Visualization Lab** (Three.js) for high-complexity topics.
